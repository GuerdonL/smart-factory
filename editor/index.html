Inside an evaluation frame, drag a neuron to move it or drop it into a vector, drag a vector by its brackets (pull a bracket outward to lengthen it), drag the small dot on a neuron onto another neuron to connect them, and drag across empty space to box-select.

      A graph predicts whenever its inputs are connected. It can also train when a loss travels back through it: wire a Cost function's loss into a frame's backprop input, and each block's bottom-left port into the backprop input of the block before it (an Attention block's is at its bottom right). Every block a gradient reaches this way is trained; there is no separate switch. Tick Positions on an Attention block when the task depends on order, and use its Weights button to see its query, key and value weights.
      
        
      To train, right-click any block of the graph. Run locally trains on the machine that serves this page (a small one: one run at a time, with a time limit); Run on GPU rents a machine through box-boy after showing what it will cost. Only the blocks behind that graph's Cost function are sent, never anything else on the canvas, and the weights come back into the blocks when the run ends. Without a server behind the page, the menu offers training in the browser instead.
      
        
      A Tokenizer has three outputs: the tokens; their labels, which are the same text one token later, so each token's label is the token that follows it; and next, the one token that follows the whole context. Set it to one-hot to get a row per token over a fixed alphabet of 97 characters. A Cost function given one-hot labels like these scores each row separately with cross-entropy, and accepts a frame's flat output of the same total size.
      
        
      A Distribution block describes random numbers (uniform between a low and a high, or normal with a mean and a standard deviation). Wire it into a Random sampler to get that many draws as a float vector. The draws stay the same until you press Resample or Play.
      
        
      Export model saves the same blocks as a file for the trainer project's command line (python run.py models/<file>.json), and Import weights loads a result back.
